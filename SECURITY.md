# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub: on this repository, open the **Security** tab and choose
**Report a vulnerability**. The report is visible only to the maintainers until a fix is published.

Include what you found, the version or commit, and the steps to reproduce it. Never include real
credentials, tokens or personal data from your installation; use placeholders.

## What happens next

The maintainers confirm they received the report, assess it, and agree with you on a date to
publish the fix and the advisory. Credit is given in the advisory unless you ask otherwise.

## Supported versions

Solidvs is before version 1.0. Fixes go to the latest release only; upgrade to it to receive them.
